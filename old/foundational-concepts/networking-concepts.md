# Networking Concepts

### MAC Address

Media Acces Control adress is a 48-biy hardware identifies assigned to a network interface controller, used to uniquely identify that specific piece of hardware or network segment. It is often called the physical address because it is tied to that specific piece of hardware.

### Port

A port is a 16-bit number (0 - 65535) that identifies a specific applciationor service running on a device, so that traffic arriving at an IP adress knows exactly which program should receive it.&#x20;
