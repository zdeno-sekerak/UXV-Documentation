# Ground Control Stations (GCS)

UXV Technologies GCS integrate a (Windows/Linux/Android) computer and a [Joystick](https://en.wikipedia.org/wiki/Joystick)/[Gampead](https://en.wikipedia.org/wiki/Gamepad) into a single unit.&#x20;

### Handheld GCS

Handheld GCS, as the name suggests, can be easily held in hand and carried around.

### GCS for Stationary Operations

GCS for Stationary Operations are intended to be used in one place at a time, with the ability to be easily transported.
