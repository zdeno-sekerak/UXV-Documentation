# Doodle Labs Radio Guides

The following subpages explain the complete process of using a standalone Doodle Labs radio, ranging from connecting to it to using it to control an unmanned vehicle through ethernet.

This guide is also useful if you wish to integrate a product of UXV Technologies with a DoodleLabs radio and need to understand its innter workings.

{% hint style="info" %}
This guide only covers the basics of using a DoodleLabs radio. If you need more advanced use case, visit theire [technical library](https://kb.doodlelabs.com/).
{% endhint %}

The first part of the guide focuses solely on explaining how to power on and connect to a DoodleLabs radio:

1. [Physical Connection with an Evaluation Board](physical-connection-with-an-evaluation-board.md)
2. [Physical Connection without an Evaluation Board](physical-connection-without-an-evaluation-board.md)
3. [Connecting Doodle Labs radio to a PC (Windows)](connecting-doodle-labs-to-a-pc-windows.md)
4. [Configuring the DL Radios connection](configuring-the-dl-radios-connection.md)
5. [Optimizing Doodle Labs Software Settings ](optimizing-doodle-labs-software-settings.md)

In the second part, the guides focus on Integrating a standalone Doodle Labs radio into an unmanned vehicle

1. [Wiring for Control of Unmanned Vehicle using SBUS](wiring-for-control-of-unmanned-vehicle-using-sbus.md)
2. [Configuring an Unmanned Vehicle with SBUS](controlling-an-unmanned-vehicle-with-sbus.md)
3. [Troubleshooting SBUS Connection](troubleshooting-sbus-connection.md)
4. [Connecting a PX4 Unmanned Vehicle with Ethernet and QGC](controlling-an-unmanned-vehicle-with-ethernet-and-qgc.md)
