# Vehicle Controller Firmware

Vehicle Controller firmware is the software responsible for converting user inputs into vehicle movements. It uses sensor data to aid the decisions.

UXV Technologies products have been tested with _PX4_ and _Ardupilot_ vehicle controller firmware:

### PX4

[PX4](https://docs.px4.io/main/en/) is a flight controller firmware, which works best with drones, or airplanes.&#x20;
