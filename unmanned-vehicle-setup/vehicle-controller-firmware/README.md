# Vehicle Controller Firmware

Flight controller firmware converts user inputs into vehicle movements. It uses sensor data to support its control decisions, while also sending some of it to the user as telemetry.

UXV Technologies products have been tested with _PX4_ and _Ardupilot_ vehicle controller firmware:

### PX4

[PX4](https://docs.px4.io/main/en/) is flight controller firmware that supports a wide variety of vehicle types. Its main development target frame is multicopters and VTOL and fixed-wing aircraft.

### ArduPilot

[ArduPilot](https://ardupilot.org/) is an open source autopilot system supporting many vehicle types:

* Multi-copters.
* Traditional Helicopters.
* Fixed wing aircraft.
* Rovers.
* Submarines/boats.
