# Choosing an Antenna

{% hint style="info" %}
Hint: If you are unsure about antenna selection, you can always contact UXV Technologies or Doodle Labs directly for help.
{% endhint %}

Then antenna selectinon is mainly influenced by the following factors:

1. Frequency - An antenna can either be optimized for one, or multiple frequency bands.
   1. The tradeoff for having an antenna which can do more frequencies is that the performance for any single one of them will be lower than for an antenna made for a single frequency.
2. Polarization - Linear or Circular
