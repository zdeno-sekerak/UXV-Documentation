# Controlling an Unmanned Vehicle with Ethernet and QGC - WHAT ABOUT SRM, WOULD MAKE SENSE TO USE IT

{% hint style="info" %}
This guide assumes you have a working communication link between the radios and have an option to connect the flight controller to one of the radios.
{% endhint %}

{% hint style="warning" %}
This guide only focuses on UXV controllers running Windows operating system, however the setup for Linux and Android should be similar.
{% endhint %}

Part list:

* 2x Doodle Labs Radio - Working and optimized link
* 1x Vehicle Controller with PX4
* 1x SRoC Controller (or any other UXV controller with windows)
* 1x SRM-RJ45 (or any other RJ-45 adapter which can be connected to the controller, can be a basic one bought online even)
